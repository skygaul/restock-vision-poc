# 사진으로 세는 음료 재고조사 PoC

진열대·냉장고 사진을 찍으면 AI가 음료 용기를 찾아 제품별로 세고, 재고표와 발주 제안까지 만들어 주는 PoC입니다.

> **진행 중.** 정답과 평가 기준을 모델 실행 전에 이 저장소에 먼저 커밋했고, 후보 3개를 평가셋(12장)으로 한 번 판정했습니다. **세 후보 모두 성공 기준(총 개수·제품별 정확도·발주 일치)을 넘지 못했습니다**(평가셋 제품별 정확도 0.30~0.48, 기준 0.70). 원인 분석과 다음 개선 시도는 [검증결과.md](검증결과.md)에 있습니다.

## 파이프라인 (계획)

```
진열대 사진 → 용기 찾기(YOLO / SAM 2) → 제품 구분(SigLIP 2)
           → 제품별 개수(재고표 CSV) → 발주표 CSV → 확인용 이미지 → 사람이 확인
```

## 데이터

- `data/photos/`: 평가용 20장 (2026-11-17 매장 음료 진열대 직접 촬영, 긴 변 3000px)
- `data/ground_truth.csv`: **사람이 센 최종 정답**
- `data/ground_truth_draft.csv`: AI가 4장만 써 본 초안(정답 아님, 비교용)
- `data/count_marks.json`, `data/human_count_time.csv`: 클릭 도구로 센 점 위치와 시간

## 정답 만들기 도구

`tool/index.html`을 브라우저로 열면 사진 속 용기를 클릭해 제품별로 셀 수 있습니다. 사진 복사본과 목록은 아래 명령으로 다시 만듭니다.

```bash
python scripts/prepare_photos.py "<원본 사진 폴더>"
```

## 실행 방법

Colab에서 후보 비교 노트북을 엽니다: [01_candidate_comparison.ipynb](https://colab.research.google.com/github/skygaul/restock-vision-poc/blob/main/notebooks/01_candidate_comparison.ipynb)

1. 런타임 → 런타임 유형 변경 → **T4 GPU**
2. 위에서부터 셀을 차례로 실행(저장소를 자동으로 내려받고 필요한 패키지를 설치합니다)
3. 개발셋(쉬움 8장)에서 값을 정하고 `results/chosen_params.json`에 저장 → 같은 값으로 평가셋(12장) 판정

> 노트북은 작성 후 아직 Colab에서 실행해 확인하지 않았습니다.

지표는 `python scripts/evaluate.py <예측 CSV>`로 계산합니다(사람 기준선은 `--no-other`).
